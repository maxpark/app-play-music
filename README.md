# 🎼 Sheet Music Player

악보 이미지를 업로드하거나 카메라로 촬영하면 자동으로 분석하고 연주하는 웹 애플리케이션입니다.
피아노 / 첼로 / 바이올린 악기를 선택할 수 있으며, SATB(소프라노/알토/테너/베이스) 4성부
악보의 각 파트를 독립적으로 재생합니다.

## 기능

| 기능 | 설명 |
| --- | --- |
| 📁 이미지 업로드 | PNG/JPG 악보 스캔본 업로드 |
| 📷 카메라 촬영 | 모바일/데스크탑 웹캠으로 직접 촬영 |
| 🎵 MusicXML | 가장 정확한 입력 방식 (.xml/.musicxml) |
| ⭐ 샘플 | 번들된 샘플 악보 (단성부 / SATB 4성부) |
| 🎹 악기 선택 | 파트별로 피아노 · 첼로 · 바이올린 변경 |
| 🎚️ 파트 제어 | Mute · Solo · 볼륨 · 악기 |
| ⏱️ 박자 인식 | 악보의 박자 표시(예: 3/4, 4/4)에 따라 재생 속도 조정 |
| 🎼 SATB | 소프라노/알토/테너/베이스 자동 인식 (MusicXML), 휴리스틱 분류 (이미지) |

## 기술 구성

* **순수 HTML / CSS / ES Modules** (빌드 단계 없음)
* **[Tone.js](https://tonejs.github.io/)** — 오디오 합성 및 트랜스포트
* **[tonejs-instruments](https://github.com/nbrosowsky/tonejs-instruments)** — 실제 악기 샘플 (피아노/첼로/바이올린)
* **순수 Canvas API** — OMR(악보 인식) 휴리스틱 파이프라인 (외부 OMR 라이브러리 미사용)

### OMR 파이프라인 (이미지 입력 시)

1. 그레이스케일 변환 + Sauvola 적응 이진화
2. 행 단위 어두운 픽셀 히스토그램으로 오선(staff line) 검출
3. 5선씩 그룹화하여 stave 영역 결정
4. 세로로 길게 이어지는 픽셀을 제거(=오선 제거)하여 음표 머리(notehead) 후보 검출
5. 연결 컴포넌트 라벨링으로 blob 추출 → 크기/비율 필터
6. 오선 기준 수직 위치로 음높이(pitch) 추정
7. 세로 막대 검출로 마디선(barline) 인식 → 각 마디 안의 음표를 균등 분할

> ⚠️ 본 OMR은 ML 기반이 아닌 휴리스틱 기반이라 깨끗한 인쇄/스캔 악보에 한해 동작합니다.
> 박자/리듬 인식의 정확도는 제한적이며, 가장 정확한 결과를 얻으려면 MusicXML 입력을 권장합니다.

### 박자 인식과 재생 속도

* MusicXML: `<sound tempo="N"/>` 디렉티브와 `<time>` 박자 태그를 직접 파싱하여 BPM과 박자 표시를 그대로 적용
* 이미지: 마디선 개수와 음표 분포로 4/4 박자 가정. 사용자가 BPM 슬라이더로 조정 가능

## 실행 방법

ES Modules는 `file://` 프로토콜에서 동작하지 않으므로 로컬 웹 서버가 필요합니다:

```bash
# 옵션 1: Python (권장)
python3 -m http.server 8000

# 옵션 2: Node 한 줄 서버
npx serve .

# 옵션 3: Caddy / nginx 등 무엇이든 정적 파일 서빙 가능
```

브라우저에서 `http://localhost:8000` 접속.

> 카메라 기능은 https:// 또는 localhost 에서만 동작합니다 (브라우저 보안 정책).

## 디렉토리 구조

```
.
├── index.html              # 진입점
├── css/styles.css          # 스타일시트
├── js/
│   ├── main.js             # UI / 오케스트레이션
│   ├── musicxml.js         # MusicXML 파서 (SATB 지원)
│   ├── omr.js              # 이미지 OMR 휴리스틱 파이프라인
│   ├── player.js           # Tone.js 기반 멀티트랙 재생기
│   └── camera.js           # getUserMedia 카메라 캡처
└── samples/
    ├── twinkle.musicxml    # 단성부 멜로디
    ├── satb-amen.musicxml  # SATB 4성부 화음
    └── scale-3-4.musicxml  # 3/4 박자 음계
```

## 사용 흐름

1. **입력 선택**: 4개 탭 중 하나에서 악보 입력
   - 이미지 업로드 / 카메라 촬영 / MusicXML 업로드 / 샘플 선택
2. **자동 분석**: 박자 · 조성 · 파트 · 음표 검출 결과 표시
   - 이미지 입력 시 검출된 오선/마디선/음표가 색상 오버레이로 표시됨
3. **재생 제어**:
   - BPM 슬라이더, 마스터 볼륨
   - 파트별 악기 선택 (피아노/첼로/바이올린)
   - 파트별 Mute / Solo / 볼륨

## 알려진 제한 사항

* 압축된 `.mxl` 파일은 미지원 (압축 해제 후 `.xml` 사용)
* 임시표(♯/♭/♮)는 MusicXML에서만 정확히 인식됨
* OMR은 깨끗하고 똑바른 흑백 인쇄 악보에 최적화됨 (손글씨/사진 왜곡에 취약)
* 음표 길이는 OMR에서 마디 균등 분할로 근사함
