# 🎼 성가대 악보 미리듣기 (Choir Score Preview)

성가대 대원이 **새로운 악보를 받았을 때** 혼자서도 파트별 음정과 박자를
미리 들어보고 연습할 수 있도록 하는 웹 서비스입니다.

## 📱 폰에서 바로 테스트 (사전 리뷰용)

설치·배포 없이 아래 링크만 열면 됩니다. HTTPS 이므로 카메라/오디오도 정상 동작:

**https://raw.githack.com/maxpark/app-play-music/claude/choir-music-preview-MhFc5/index.html**

폰으로 QR 스캔이 더 편하시면 저장소 루트의 **[`preview.html`](./preview.html)** 을 PC 브라우저에서 열면 큼지막한 QR 코드가 나옵니다. 폰 카메라 앱으로 스캔 → 끝.

| 대상 | 추천 경로 |
| --- | --- |
| 폰에서 바로 | 위 raw.githack URL 직접 열기 |
| PC → 폰 공유 | `preview.html` 열고 QR 스캔 |
| 팀원 여러 명 공유 | `npx surge .` 로 영구 `*.surge.sh` URL 발급 |
| 로컬 개발 | `python3 -m http.server 8000` |

---

샘플 / MusicXML / 이미지 / 카메라 중 원하는 방식으로 악보를 입력하면,
SATB (소프라노·알토·테너·베이스) 4성부 또는 단성부 악보를 자동 인식하여
파트별로 음량과 악기를 조절해 가며 연주합니다.

## 💡 성가대 대원을 위한 사용 흐름

| 단계 | 화면 동작 | 목적 |
| --- | --- | --- |
| 1. 들어보기 | ‘전체 같이’ 프리셋 + ▶ 재생 | 곡의 전체적인 느낌 파악 |
| 2. 음정 익히기 | ‘내 파트만 듣기’ 프리셋, 🐢 0.5× 속도, 🎹 음정 미리듣기 | 낯선 음정을 귀로 익힘 |
| 3. 리듬 익히기 | 🥁 메트로놈 ON, 🔢 카운트인 ON | 박자 감각 훈련 |
| 4. 구간 집중 연습 | 🔁 A/B 지점 설정 → 반복 재생 | 어려운 마디를 반복 |
| 5. 실제 연습 | ‘내 파트 mute (가이드 모드)’ | 반주만 들으며 직접 노래 |

## ✨ 주요 기능

### 입력
- **⭐ 샘플**: 번들된 SATB / 단성부 악보로 즉시 체험
- **🎵 MusicXML**: 가장 정확한 입력 (.xml / .musicxml)
- **📁 이미지 업로드**: 휴리스틱 OMR 파이프라인
- **📷 카메라 촬영**: 모바일/데스크탑 webcam 직접 촬영

### 연주 · 연습 (Step 3)
- **▶ 재생 / ❚❚ 일시정지 / ■ 정지** — 언제든 이어 재생 가능
- **BPM 슬라이더** + **속도 프리셋** (0.5× · 0.75× · 1.0× · 1.25×)
- **🥁 메트로놈** — 마디 첫 박 강조 (C6), 나머지 박자(G5) 클릭음
- **🔢 카운트인** — 재생 전 1마디의 메트로놈 클릭
- **🎯 내 파트 연습 프리셋**
  - 🎙️ 내 파트만 듣기 (다른 파트 mute)
  - 🤫 내 파트 mute (가이드 모드 — 반주만 들으며 노래)
  - 📖 내 파트 크게 + 반주 작게 (학습용)
  - 👥 전체 같이 (초기 상태)
- **🎻 파트별 설정** — 악기(피아노/첼로/바이올린/**🗣️ 보컬 합성**) · 볼륨 · Mute · Solo
- **🔁 구간 반복 연습** — A / B 지점 설정으로 어려운 구간 무한 반복
- **📍 현재 마디 / 박자 표시** — 악보 어디를 지나고 있는지 실시간 확인
- **🎹 음정 미리듣기 키보드** — 악보에 포함된 음은 하이라이트. 원하는 건반을 클릭해 선택한 악기로 단음 확인
- **클릭 시 시킹** — 진행바의 원하는 지점을 클릭해 바로 이동

## 기술 구성

* **순수 HTML / CSS / ES Modules** — 빌드 단계 없음
* **[Tone.js 14](https://tonejs.github.io/)** — 오디오 합성, 트랜스포트, 루프, 시킹
* **[tonejs-instruments](https://github.com/nbrosowsky/tonejs-instruments)** — 피아노/첼로/바이올린 CC 라이선스 샘플
* **PolySynth (fatsine + envelope)** — 합성 보컬 악기 (“아~” 모음 느낌)
* **순수 Canvas API** — OMR 휴리스틱 파이프라인 (외부 OMR 라이브러리 미사용)

### OMR 파이프라인 (이미지 입력)
1. 그레이스케일 → Sauvola 적응 이진화
2. 행 단위 어두운 픽셀 히스토그램으로 오선 검출
3. 5선씩 그룹화하여 stave 영역 결정
4. 세로로 긴 픽셀 제거 → 음표 머리 후보 검출
5. 연결 컴포넌트 라벨링 → 크기/비율 필터
6. 오선 기준 수직 위치로 음높이 추정
7. 세로 막대 검출로 마디선 인식 → 마디 내 음표 균등 분할

> ⚠️ 본 OMR은 ML 기반이 아닌 휴리스틱이라 깨끗한 인쇄/스캔 악보에 한해 동작합니다.
> 가장 정확한 결과를 얻으려면 MusicXML 입력을 권장합니다.

## 실행 방법

ES Modules는 `file://` 에서 동작하지 않으므로 로컬 웹 서버가 필요합니다:

```bash
# 옵션 1: Python
python3 -m http.server 8000

# 옵션 2: Node
npx serve .
```

브라우저에서 `http://localhost:8000` 접속.

> 카메라 기능은 https:// 또는 localhost 에서만 동작합니다 (브라우저 보안 정책).

## 디렉토리 구조

```
.
├── index.html              # 진입점
├── css/styles.css          # 스타일시트
├── js/
│   ├── main.js             # UI / 오케스트레이션 / 연습 프리셋
│   ├── musicxml.js         # MusicXML 파서 (SATB 지원)
│   ├── omr.js              # 이미지 OMR 휴리스틱 파이프라인
│   ├── player.js           # Tone.js 기반 멀티트랙 재생기 (메트로놈·루프·보컬 합성)
│   └── camera.js           # getUserMedia 카메라 캡처
└── samples/
    ├── hymn-eb-3-4.musicxml   # 찬송풍 SATB 데모 (Eb major, 3/4)
    ├── satb-amen.musicxml     # SATB 카덴차 (F major, 4/4)
    ├── twinkle.musicxml       # 단성부 (C major, 4/4)
    └── scale-3-4.musicxml     # 음계 (3/4 박자 시연)
```

## 알려진 제한 사항

* 압축된 `.mxl` 파일 미지원 (해제 후 `.xml` 사용)
* 임시표(♯/♭/♮)는 MusicXML에서만 정확히 인식
* OMR은 깨끗한 인쇄 악보에 최적화 (손글씨/사진 왜곡에 취약)
* OMR에서의 음표 길이는 마디 균등 분할로 근사
